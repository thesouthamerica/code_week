# SI Code Week 2026 · Desafio 0 · Tutorial

Este repositório é seu. Só você e a Coordenação conseguem ver.

## O que fazer aqui

1. Abra o arquivo `sobre-mim.md`, clique no lápis e complete as linhas.
2. Clique em **Commit changes**.
3. Copie o endereço da página do commit (ou o SHA de 40 caracteres) e cole no formulário do Desafio 0, no sistema da SI Code Week.

## Opcional: testar o Python

Os Desafios 02 e Final usam **Python 3.12**, só com a biblioteca padrão.

```
python ola.py
```

Se aparecer "tudo certo", seu computador está pronto.

Instruções completas: página do Desafio 0 no sistema.
